# Invoice Generator

A simple, single-file invoice generator. Fill in your details, add line items, then print/save as PDF or copy an email-ready plaintext version.

- **Profiles:** keep separate saved setups (e.g. different businesses, clients or jobs) and switch between them from the dropdown. Create, duplicate, rename and delete profiles.
- **Auto-save:** everything is saved in your browser's `localStorage` as you type. Nothing is sent to any server.
- **Export / Import JSON:** move all your profiles between computers or browsers. Import merges into existing profiles (same-named ones are overwritten after confirmation).
- **Clear All Saved Data** wipes everything on that device.

Note: exported JSON contains your business and client details, so keep it private.
